# Project Documentation Hub

Welcome to the detailed documentation for the **LLM and VTK Driven Environment Visualization System**.

This section provides in-depth information about the project's architecture, visualization components, and the mechanisms for interacting with the system using Large Language Models.

## Navigation

Please use the links below to navigate to specific sections of the documentation:

*   **[Architecture (`architecture.md`)](architecture.md)**: Understand the overall system design, how different parts (LLM, Python backend, VTK) interact, and the roles of key scripts and modules.
*   **[Visualization Components (`components.md`)](components.md)**: Learn about each environmental component that can be visualized (e.g., Atmosphere, WaterBody, Ecosystem), including their visual representation and any data-driven customization options.
*   **[LLM Interaction (`llm_interaction.md`)](llm_interaction.md)**: Discover how natural language commands are processed, the current parsing strategies, how these commands map to visualization actions, and details about the LLM used.

For a general overview, setup, and running instructions, please see the main [Project README.md](../README.md).
